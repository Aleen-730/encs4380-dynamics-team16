Methods you can use

  • First order, step: y(τ) = 0.632 K A, so find the time where the curve reaches 63.2% of the final value. Or use the log method: ln of the error fraction against t is a line with slope −1/τ.
  • First order, sine: amplitude ratio M = 1/√(1+(ωτ)²) and phase lag φ = tan⁻¹(ωτ). The output amplitude is K·M.
  • Second order, step: read the overshoot and the peak time. Then find ζ and ωn.
  • Hover over the plot to read exact values. The step amplitude is A = 1.
  • Scoring: within 10% error is full marks for that parameter. The points then fall to 0 at 50% error.
