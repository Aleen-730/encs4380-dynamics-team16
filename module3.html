Rise Time: 10%–90% of final value. Settling Time: ±2% criterion. Measurements are calculated from the response curve.

Live Measurement Formulas

1. Rise Time (10%–90%)
tr = t90% − t10%
2. Theoretical Rise Time (Underdamped)
tr = (π − φ) / ωd
φ = cos⁻¹(ζ)
ωd = ωn √(1 − ζ²)
3. Peak Time
tp = π / ωd
4. Maximum Overshoot
%OS = e−πζ / √(1−ζ²) × 100%
5. Settling Time (2% Criterion)
|y(t) − yfinal| ≤ 0.02 × yfinal

Equations Used

1. Characteristic Equation
s² + 2ζωn s + ωn² = 0

2. Poles
s1,2 = −ζωn ± ωn√(ζ² − 1)

3. Damped Natural Frequency
ωd = ωn√(1 − ζ²)

4. Underdamped Response (ζ < 1)
y(t) = 1 − e−ζωn t [cos(ωd t) + ζ/√(1 − ζ²) sin(ωd t)]

5. Critically Damped Response (ζ = 1)
y(t) = 1 − (1 + ωn t)e−ωn t

6. Overdamped Response (ζ > 1)
q = √(ζ² − 1)
r1 = −ωn(ζ − q)
r2 = −ωn(ζ + q)
y(t) = 1 + [r2er1t − r1er2t] / (r1 − r2)
